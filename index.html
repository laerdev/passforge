How to read the numbers

Entropy

Entropy in bits measures how many guesses an attacker has to work through. Each extra bit doubles the work. Under 60 bits is weak for anything important, 80 bits is comfortable, and above 100 bits is out of reach of any attacker we know how to build.

Brute force time

The time shown is the average: half the search space, at the guessing rate you picked. Real attackers try common words, dates and substitutions first, which is why a password from a random generator beats one you invented yourself.

Characters or words?

Random characters pack the most entropy into the fewest keystrokes, so they are ideal for anything a password manager types for you. A word phrase reaches the same strength with more length, and you can actually remember it, which makes it the better choice for the handful of passwords you type by hand.

Where these come from

Every character and every word is drawn with crypto.getRandomValues, the browser's cryptographic random source, using rejection sampling so that no value is more likely than any other. The page has no analytics and no backend.
