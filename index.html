How this works

Real randomness

Characters and words are drawn with crypto.getRandomValues and rejection sampling, so every option is equally likely. No shortcuts, no seeded pseudo-randomness.

The word list

Passphrases use the EFF long word list: 7,776 distinct English words, each one worth 12.9 bits. A three word phrase is far easier to remember than a random string of the same strength.

Nothing leaves this page

There is no server-side generator, no analytics and no logging. Close the tab and the password is gone, so save it in a password manager before you leave.
